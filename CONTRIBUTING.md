# Contributing

Changes must preserve the one-repository/one-distribution boundary, the stable
Meridian V1 contracts, fail-closed validation, secret redaction, deterministic
artifacts, and Apache-2.0 licensing. Architecture or public-interface changes
require an approved design update before implementation.

Use a pull request, keep CI green, and include tests and release evidence for
observable behavior changes.
